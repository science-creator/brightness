# ⭐ 별의 밝기와 등급 실험실

중학교 3학년 과학 「별과 우주」 — **별의 밝기와 등급**을 눈으로 확인하는 수업용 웹 앱.
성취기준 **[9과23-01]** (2015 개정).

> 별의 거리를 구하는 방법을 알고, 별의 표면 온도를 색으로 비교할 수 있다.

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.
(인터넷도, 파이썬도, npm 도 필요 없습니다.)

| 화면 | 파일 | 하는 일 |
|---|---|---|
| ⭐ 실험실 | `index.html` | 거리·등급·절대 등급·색을 직접 바꿔 본다 |
| 📝 학습지 | `worksheet.html` | 21문항을 풀고 PDF 로 제출한다 (17문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🗂️ 선생님용 | `teacher.html` | 학생이 낸 PDF 를 파일 이름만 읽어 제출 현황으로 정리한다 |

## 무엇을 보여 주나

- **멀어지면 왜 어두워질까** — 빛이 퍼지는 넓이를 **격자**로 그립니다.
  거리가 2배가 되면 같은 빛이 **4칸**에 나뉘어요. 그래서 밝기는 1/4입니다.
- **등급이라는 약속** — 1등급은 6등급보다 **100배** 밝고, 1등급 차이마다 **약 2.5배**.
  두 별의 등급을 바꾸면 몇 배 밝은지 숫자로 나옵니다.
- **겉보기 등급과 절대 등급** — 별을 **10 pc**로 끌어다 놓아 보세요.
  그 자리에서 보이는 등급이 절대 등급입니다.
- **색과 표면 온도** — 청색이 가장 뜨겁고 적색이 가장 차갑습니다.

## 이 앱이 남기고 싶은 한 문장

> **밝게 보인다고 실제로 밝은 별은 아니다.**
> 가까이 있어서 밝아 보일 수 있으니, 진짜 밝기를 견주려면
> 모두 **10 pc의 같은 거리에 세워 놓고** 비교해야 한다.

미션 6에서 시리우스와 베텔게우스를 10 pc에 나란히 세워 보면 바로 보입니다.

## 미션 6개

예측 → 확인. 성공해야 이유가 열립니다.

1. 🔦 2배 멀어지면? · 2. 📉 밝기를 9분의 1로 · 3. ⭐ 100배 밝게
4. 🔍 한 등급의 무게 · 5. 📏 10 pc 로 옮겨라 · 6. 🌟 진짜 밝은 별은?

## 인쇄

학습지를 열고 `Ctrl+P` — **A4 두 쪽**으로 나옵니다. 이름 쓰는 칸이 있는 빈 학습지예요.
표 머리글의 회색과 서술칸 줄무늬가 필요하면 인쇄 창에서 **「배경 그래픽」**을 켜세요.
